# Global Shipping & Logistics Companies Analysis

## Project Overview

This project analyzes a dataset of 60 international shipping and logistics companies collected from publicly available online sources.

The objective was to demonstrate the complete data analytics workflow, from data collection and cleaning to SQL analysis and Power BI dashboard development.

## Project Objectives

* Collect real-world logistics company data from public sources.
* Structure and clean the dataset using Excel.
* Import the dataset into SQL for querying and analysis.
* Build an interactive Power BI dashboard.
* Generate business insights from the data.

## Dataset Information

The dataset contains:

* 60 Shipping & Logistics Companies
* 21 Countries
* Multiple Cities Worldwide
* Company Contact Information
* Company Websites

## Tools Used

* Microsoft Excel
* SQL
* Power BI

## SQL Analysis Performed

* Total company count
* Country distribution analysis
* City distribution analysis
* Top logistics hubs identification
* Data quality checks

## Key Findings

* Nigeria recorded the highest number of logistics companies in the dataset.
* The United Kingdom ranked second.
* The United States ranked third.
* Lagos emerged as the dominant logistics hub within Nigeria.
* London represented the largest logistics cluster in the UK segment.
* New York accounted for the majority of the US-based logistics companies.

## Dashboard Features

* KPI Cards
* Companies by Country
* Top Cities Analysis
* Interactive Slicers
* Company Directory Table

## Business Recommendations

* Focus partnership opportunities on highly represented logistics markets such as Nigeria, the United Kingdom, and the United States.
* Explore emerging logistics markets for future expansion opportunities.
* Expand future datasets to include company size, services, and revenue information for deeper analysis.
